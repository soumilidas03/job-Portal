# 🚀 Job Hunter – MERN Stack Job Portal

A full-stack **Job Portal Web Application** built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)** that connects **Job Seekers** with **Recruiters** through a scalable and intuitive platform.

This platform enables applicants to browse and apply for jobs while allowing recruiters to post and manage company job listings via a dedicated admin dashboard.

---

## 📌 Features

### 👩‍💻 Job Seeker Functionalities

- 🔐 Secure Authentication (JWT-based Login/Register)
- 👤 Profile Creation & Management
- 📄 Resume Upload (PDF)
- 🔍 Job Search by:
  - Job Title
  - Location
  - Industry
  - Salary Range
- 💼 Apply to Jobs
- 📊 Track Applied Jobs Status
- 🧠 Add & Manage Skills

---

### 🏢 Recruiter / Admin Functionalities

- 🏢 Add & Manage Companies
- 📢 Post New Job Listings
- ✏️ Update / Delete Job Posts
- 📋 View Available Jobs
- 👨‍💼 View Applicants
- 🔎 Search Jobs by Name

---

## 🧰 Tech Stack Used

| Technology    | Purpose                  |
| ------------- | ------------------------ |
| MongoDB       | NoSQL Database           |
| Express.js    | Backend Framework        |
| React.js      | Frontend Library         |
| Node.js       | Runtime Environment      |
| Redux Toolkit | State Management         |
| JWT           | Authentication           |
| Multer        | Resume Upload            |
| Cloudinary    | File Storage             |
| Tailwind CSS  | Styling                  |
| shadcn/ui     | Accessible UI Components |
| Axios         | API Communication        |

---

## 🎨 UI & Design System

The frontend UI is built using:

- Tailwind CSS for responsive utility-first styling
- shadcn/ui for modern and accessible components

Reusable UI components include:

- Dialogs
- Cards
- Buttons
- Inputs
- Tabs
- Toast Notifications
- Dropdown Menus

This ensures:

✔ Clean UI/UX  
✔ Component Reusability  
✔ Accessibility Compliance  
✔ Scalable Design System
